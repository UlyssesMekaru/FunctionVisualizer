# FunctionVisualizer

Software desenvolvido em C utilizando a biblioteca Raylib para visualização gráfica de funções matemáticas.

## Objetivo

O objetivo deste projeto é representar graficamente funções afins e quadráticas em um plano cartesiano, permitindo a visualização do comportamento das funções e de seus coeficientes.

## Funcionalidades

- Plotagem de funções afins
- Plotagem de funções quadráticas
- Exibição do plano cartesiano
- Exibição da equação na tela

## Tecnologias utilizadas

- Linguagem C
- Raylib
- GCC

## Como executar

Compile o programa utilizando GCC e Raylib.
Ajuste os caminhos de include e biblioteca de acordo com a instalação da Raylib em seu sistema.

## Dependências 

Esse projeto utiliza a biblioteca Raylib: 
https://www.raylib.com/
